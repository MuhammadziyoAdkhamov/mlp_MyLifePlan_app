# MYLife Plan - Acceptance Criteria (Definition of Done)

The MVP is complete only when the following criteria are met and verified:

- [x] Existing useful MLP functionality has been audited and preserved where appropriate.
- [x] The application starts successfully.
- [ ] Registration/authentication works using a configured real method (Existing Google/Guest auth verified).
- [ ] The user can create a custom goal without choosing a preset.
- [ ] The diagnostic produces a structured result.
- [ ] The user can review, edit, and approve a roadmap.
- [ ] The home screen identifies the next useful learning action.
- [ ] Lessons and exercises are connected.
- [ ] Answers produce meaningful feedback.
- [ ] Attempts and progress persist.
- [ ] Assessment outcomes influence the next learning step.
- [ ] Mastery is not falsely inferred from activity alone.
- [ ] Review items can be scheduled and completed.
- [ ] Navigation and responsive layouts work (DashboardShell refactored to preserve state).
- [ ] Loading, empty, error, and offline states are handled.
- [ ] Security rules prevent unauthorized access to other users' data (Documented for Firestore).
- [ ] No production AI key is exposed in the client.
- [ ] Critical automated tests exist and pass in the available environment.
- [ ] Unconfigured integrations are clearly identified rather than faked (e.g. AI backend development mode).
- [ ] Setup instructions and known limitations are documented.
